# Esca WebAssembly interface

This narrow JSON buffer adapter links unmodified Esca 0.4.0 from [commit 5c801e7fa716a4a8691a51f4adcd33d9c362b93d](https://github.com/AnglerfishChess/esca/tree/5c801e7fa716a4a8691a51f4adcd33d9c362b93d). Rust 1.93.0; only the `serde` feature enabled. For a build, download that exact source archive and extract beside this folder under its commit-named directory `esca-5c801e7fa716a4a8691a51f4adcd33d9c362b93d`. Install the Rust `wasm32-unknown-unknown` target and run `cargo +1.93.0 build --locked --target wasm32-unknown-unknown --release` in this folder. Dependencies are locked; gzip the built module into `engine/esca.wasm.gz`. The published demo uses an already verified build; reproduction can differ in byte representation across environments. See `../../licenses/esca-0.4.0/LICENSE` and the dependency notices.
